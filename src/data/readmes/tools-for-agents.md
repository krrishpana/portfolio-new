# Tools for Agents

Building **custom tools** for AI agents and measuring **how well the agents use them**.

## The idea

An agent becomes much more useful when it can call tools, like a calculator, a search function or an API. But agents don't always pick the right tool, or use it correctly. This experiment looks at both sides:

- **Building tools** that are clear and easy for an agent to use
- **Evaluating** how well the agent performs with them

## What I measure

- Does the agent choose the **right tool**?
- Does it pass the **right inputs**?
- Does it finish the **task correctly**?
